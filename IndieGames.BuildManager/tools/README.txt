Portable FFmpeg downloaded from:
https://raw.githubusercontent.com/imageio/imageio-binaries/master/ffmpeg/ffmpeg-win64-v4.2.2.exe

Used by scripts/Convert-XnbAudio.ps1 to decode XMA/WMA and encode PCM/Ogg.
The executable is copied to the application's tools directory during build.
You can select a different FFmpeg executable in BuildManager.
